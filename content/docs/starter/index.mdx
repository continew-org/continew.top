ContiNew Starter（Continue New Starter）基于「约定优于配置」理念，进一步精简常规配置，提供完整的配置解决方案，帮助开发人员更快速地将常用第三方库或工具集成到 Spring Boot Web 应用程序中。

它封装了一系列经过企业实践验证的依赖包（如 MyBatis-Plus、Sa-Token、Redisson、JetCache 等），可轻松集成到应用中，减少手动引入依赖及配置的工作量，为 Spring Boot Web 项目的灵活快速构建提供支持。

<Callout type="info">
当前文档对应 **2.x** 版本（基于 Spring Boot 3.x，要求 JDK 17+）。
</Callout>

## 项目起源

ContiNew Starter 源自 [ContiNew Admin](https://github.com/continew-org/continew-admin) 后台管理框架项目。随着 ContiNew Admin 的发展，作者发现初学者需要关注过多的脚手架通用基础能力，且在新项目中复用这些能力时存在迁移困难。于是在 ContiNew Admin 2.x 版本时，将这些通用基础能力抽离并深度优化，形成独立的 Starter 库——无论是在 ContiNew Admin 中使用，还是单独使用这些基础能力，都更加轻松。
