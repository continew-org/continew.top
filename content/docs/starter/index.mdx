## 什么是 ContiNew Starter

ContiNew Starter（Continue New Starter）是一套以「约定优于配置」为核心理念的企业级 Starter 库。它将一系列经过企业实践验证的第三方库（MyBatis-Plus、Sa-Token、Redisson、JetCache 等）封装为开箱即用的 Starter，让 Spring Boot Web 应用的集成更简单、更优雅。
