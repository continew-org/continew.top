ContiNew Admin（Continue New Admin）是基于 ContiNew Starter 构建的多租户中后台管理系统框架，前后端分离：后端为 Spring Boot 3.x / Java 17 的 Maven 多模块工程，前端为 Vue3 + Arco Design + TypeScript + Vite。

<Callout type="info">
本分区文档正在按最新架构重写中。文档源维护在 [continew-admin](https://github.com/continew-org/continew-admin) 仓库的 `docs/` 目录（含前端 continew-admin-ui 文档），建成后此处将展示完整文档。
</Callout>
