## 什么是 ContiNew Admin

ContiNew Admin（Continue New Admin）是基于 ContiNew Starter 构建的多租户中后台管理系统框架，前后端分离：后端为 Spring Boot 3.x / Java 17 的 Maven 多模块工程，前端为 Vue3 + Arco Design + TypeScript + Vite。
